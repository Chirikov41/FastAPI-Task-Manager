# Task Manager REST API (FastAPI CW1)
## Overview
A simple Task Management REST API built with FastAPI. It demonstrates CRUD operations, data validation, and automatic documentation.
## Setup
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. uvicorn main:app --reload
## Run Tests
python -m pytest -q
